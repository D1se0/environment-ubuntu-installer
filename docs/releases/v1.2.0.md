## ✨ Qué hay de nuevo

### El prompt ahora muestra tu nombre de usuario

A la izquierda de la ruta aparece siempre el usuario actual:

```
 ◈  │ diseo ~/labos/htb ✓ $     ← usuario normal (gris claro)
 ◈ ☠  │ root /etc ✓ #           ← root (en rojo, con calavera)
```

- **Gris claro** como usuario normal · **rojo whitehat** cuando eres root
- Se calcula en cada prompt (`\u`), así que `su`/`sudo -i` lo reflejan al instante

### Ctrl+W reforzado en todas las capas

El cierre con confirmación **Si/No** ahora es a prueba de balas:

| Capa | Mejora |
|---|---|
| **kitty** | `map ctrl+w` lanza el diálogo internamente (la tecla nunca llega al shell) |
| **sxhkd** | Atajo global para el resto de ventanas. **Nota:** si en una sesión ya abierta deja de responder, recárgalo con `pkill -USR1 -x sxhkd` (o reinicia sesión: los logins nuevos lo cargan automáticamente) |
| **bash** | 5 binds CSI-u cubriendo **todas** las codificaciones posibles de la tecla (`119;5u`, `87;5u`, `23;5u`, `9;9u`, `119;7u`) — si una terminal deja escapar la secuencia, bash la interpreta y lanza el mismo diálogo |
| **Diagnóstico** | Cada invocación queda registrada en `/tmp/whitehatso-close.log` con hora y origen — si algo fallara, se sabe al instante si la tecla llegó o no |
| **Robustez** | Autodetección de `DISPLAY` y del socket de bspwm cuando el lanzador no aporta entorno; guard anti-duplicados (si ya hay un diálogo abierto no apila otro) |

## ⬆️ Actualizar desde v1.0.x / v1.1.0

El instalador es **idempotente**: ejecútalo otra vez y aplica solo lo que falte.

```bash
bash install-whitehatso.sh
```

📥 Descarga directa: [install-whitehatso.sh](../../releases/download/v1.2.0/install-whitehatso.sh) · también desde `main` con el one-liner del README.

Manual (sin reinstalar): el nuevo prompt vive en el bloque `# >>> whitehatSO prompt >>>` de tu `~/.bashrc`, y el diálogo en `/usr/local/bin/whitehatso-close`.
