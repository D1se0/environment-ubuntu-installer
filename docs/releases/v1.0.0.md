## 🎯 Qué es whitehatSO

No es una distribución nueva: es un **conjunto de configuraciones, scripts y ajustes de sistema** que transforman un Ubuntu 25.10 recién instalado (o el tuyo de siempre) en un entorno pensado para ciberseguridad ofensiva/defensiva, con estética terminal roja (#e0303c) y filosofía *minimal + rápido + todo bajo control*.

---

## 📦 El instalador (autocontenido)

`install-whitehatso.sh` lleva **incrustados** todos los configs, scripts, fondo del login y wallpapers — **no descarga nada del repo en tiempo de ejecución**. Un solo comando:

```bash
curl -fsSL https://raw.githubusercontent.com/D1se0/environment-ubuntu-installer/main/install-whitehatso.sh -o install-whitehatso.sh
chmod +x install-whitehatso.sh
sudo bash install-whitehatso.sh
```

Te irá preguntando qué quieres aplicar:

1. **Usuario** a configurar
2. **Paquetes base** (Xorg, lightdm, bspwm, kitty, polybar, rofi, feh, dunst, fastfetch, JetBrainsMono Nerd Font…)
3. **Rendimiento** (zram, sysctl, debloat de telemetría/servicios, Firefox .deb nativo)
4. **Login temático** lightdm (greeter GTK Yaru-red-dark, fondo generativo, JetBrains Mono)
5. **Fixes VMware** (resolución dinámica con RandR + portapapeles bidireccional)
6. **Prompt con calavera** también para root

Modo desatendido (scripting, chroots Cubic, replicar en varias máquinas):

```bash
WHS_ASSUME_YES=1 WHS_USER=tu_usuario sudo -E bash install-whitehatso.sh
```

Al terminar: cierra sesión y elige **whitehatSO (bspwm)** en el menú del login.

## 🖥️ Entorno de escritorio

| Componente | Detalle |
|---|---|
| **Gestor de ventanas** | bspwm (tiling binario) + sxhkd (atajos) + picom (compositor afinado para VM) |
| **Terminal** | kitty con paleta roja/gris, transparencia 0.92, pestañas powerline y cierre Ctrl+W con confirmación Si/No |
| **Panel** | polybar con módulo **ATK** (IP del atacante vía `settarget`), control bettercap/tor, menú de poder |
| **Prompt bash** | Logo Ubuntu + ruta absoluta + ✓/✗ del último comando + ☠ rojo y `#` en modo root |
| **Launcher** | rofi (drun) con reglas flotantes y el diálogo de cierre integrado |
| **Login** | lightdm + greeter GTK temático (Yaru-red-dark, fondo generativo rojo, JetBrains Mono) |

### Herramientas propias

| Comando | Qué hace |
|---|---|
| `whs-bettercap on\|off` | Arranca/para bettercap + tor bajo demanda |
| `whs-status` | RAM, disco, zram y estado de tor/bettercap/snapd |
| `whs-help` | Chuleta de comandos |
| `settarget 10.10.14.7` | Marca la IP objetivo → el módulo ATK de polybar la muestra en rojo |
| `whitehatso-close` | Diálogo Si/No de cierre (lo que usa Ctrl+W) |
| `whitehatso-lock` | Bloqueo con fondo borroso y anillo rojo (i3lock) |

### Atajos destacados

`super + Return` kitty · `super` rofi · `ctrl + w` **cerrar con confirmación** · `super + {1-5}` escritorios · `super + h/j/k/l` foco vim-style · `super + f` fullscreen · `super + shift + l` bloquear · `print` flameshot

## ⚡ Rendimiento

| Ajuste | Valor |
|---|---|
| zram | `min(ram, 8192)` MB, zstd, prioridad 100 |
| vm.swappiness | 10 |
| vm.vfs_cache_pressure | 50 |
| journald | 150 MB, comprimido |
| I/O scheduler | `none` (SSD/VM) vía udev |
| earlyoom | activo — mata procesos antes del congelamiento por RAM |
| Telemetría | whoopsie, apport, ubuntu-report/insights, unattended-upgrades: **purgados** |
| snapd | eliminado (Firefox .deb nativo de Mozilla) |

Estado de referencia (VM 4 vCPU / 5.3 GB): **~850 MiB RAM en reposo**, 0 unidades systemd fallidas, disco ~53%.

## 🔒 Seguridad por diseño

- **Lista de paquetes protegidos** (`xorg`, `lightdm`, `bspwm`, `mesa`, `ubuntu-desktop`, …): el debloat **jamás** los desinstala — ni por accidente
- **Backups automáticos** de tus configs en `~/.config/backups/whitehatso-<fecha>/` antes de tocar nada
- No toca tu usuario ni tus datos; es idempotente (puedes re-ejecutarlo sin miedo)
- Probado en vivo: instalación completa sobre sistema en producción sin romper la sesión
